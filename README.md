# 🛡️ ShieldClean AI - Watermark Remover & Photo Sanitizer

All production files are located in the **[`production/`](./production)** directory.

## 🚀 Vercel Deployment
- **Root Directory:** Set to `production` in Vercel project settings (or leave default, the root `vercel.json` automatically rewrites to `production`).
- **Features:** 100% client-side privacy, C2PA/EXIF metadata purge, anti-AI invisible watermark disruption, 4:4:4 ultra HD chroma, and offline PWA install support.
